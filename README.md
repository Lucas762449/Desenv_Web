## Resumo da aula

Nesta aula aprendi os conceitos básicos relacionados aos servidores web,
compreendendo como ocorre a comunicação entre cliente e servidor através
da Internet.

Também aprendi a diferença entre servidor local e servidor remoto,
além dos conceitos de ambiente de desenvolvimento e ambiente de produção.

## O que aprendi sobre servidores web

Aprendi que um servidor web recebe solicitações dos clientes, como
navegadores, e envia respostas contendo páginas, arquivos ou outros
recursos solicitados.

Também compreendi que o servidor local pode ser utilizado para
desenvolvimento e testes, enquanto um servidor remoto pode disponibilizar
o sistema para usuários através da Internet.

Além disso, entendi a importância do HTTPS para tornar a comunicação
entre cliente e servidor mais segura.
