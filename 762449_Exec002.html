O que é um servidor web?

Um servidor web é um computador ou sistema responsável por armazenar e fornecer páginas e arquivos para os usuários através da Internet ou de uma rede.

Cliente, servidor e resposta

Cliente: é o navegador do usuário, como Google Chrome, Microsoft Edge ou Firefox.

Servidor: é o computador ou sistema que recebe a solicitação do cliente e disponibiliza os recursos solicitados.

Resposta do servidor: é o conteúdo solicitado pelo cliente, como uma página HTML, imagens, arquivos ou outras informações.
